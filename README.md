# SPARK 🤖✨

DIY desk pet robot built from scratch. Zero budget. One evening.

## What SPARK does
- 13 animated eye expressions on a 0.96" OLED
- Reacts to claps — 1 clap = happy, 2 = dizzy, 3 = angry
- Goes sad if ignored for 5 seconds
- Boots up playing the Friends theme 🛋️
- Falls asleep after 5 mins of no interaction

## Hardware
- ESP32
- 0.96" OLED display (SSD1306)
- Sound sensor
- Buzzer
- Cardboard box 📦

## Cost
₹0 — built entirely from components I already had at home.
